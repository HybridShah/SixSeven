
# SixSeven 676767

Welcome to SixSeven!

SixSeven is a GitHub learning project designed to
introduce contributors to GitHub and Git version
control through practical exercises.

## Objectives

- Understand Git and GitHub.
- Learn repository management.
- Practise Git commands.
- Understand branching and merging.
- Learn how to create Pull Requests.
- Collaborate using GitHub.

## Team

| Role | Responsibility |
|---|---|
| Supervisor | Repository and training management |
| Intern | Complete assigned exercises |

## Training Roadmap

1. Getting Started
2. Git Basics
3. Branch Management
4. Pull Requests
5. Practical Exercises

## Rules

- Complete assigned exercises.
- Use separate branches for tasks.
- Write meaningful commit messages.
- Submit work through Pull Requests.
- Do not push directly to main.
